# Карточки иврита — развёртывание

Два файла: `index.html` (приложение) и `words.js` (база слов).

## Вариант 1 — GitHub Pages

1. github.com → **New repository** → имя `ivrit-cards`, Public → **Create repository**
2. **Add file → Upload files** → перетащи `index.html` и `words.js` → **Commit changes**
3. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, папка `/ (root)` → **Save**
4. Через ~1–2 минуты сайт живёт по адресу
   `https://<твой-логин>.github.io/ivrit-cards/`
5. Открой в Safari → Поделиться → **На экран «Домой»** — будет как приложение.

## Вариант 2 — Netlify (ещё проще)

app.netlify.com/drop → перетащи папку с двумя файлами → готовая ссылка.

## Как пополнять базу

Открой `words.js` на GitHub → карандаш (Edit) → добавь строки по образцу:

```js
{h:"מִלָּה", t:"мила́", r:"слово", s:6},
```

- `h` — иврит с огласовками (версия без огласовок делается автоматически)
- `t` — транскрипция с ударением
- `r` — перевод
- `s` — номер раздела (список с номерами — в шапке words.js)

Новый раздел: допиши название в массив `sections` и используй его номер.
**Commit changes** — страница обновится сама, ничего пересобирать не нужно.

## Прогресс

Хранится в localStorage браузера по адресу сайта: переживает закрытие вкладки,
перезагрузку и обновления базы. Привязан к написанию слова — если изменишь `h`,
это слово начнёт учиться заново. Между устройствами (iPhone/iPad) прогресс
не синхронизируется — у каждого свой.
